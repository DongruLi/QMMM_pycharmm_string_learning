# Build the Initial Reaction Path

Before running the string simulation, an initial reaction path is needed to connect the reactant and product regions.

For the chorismate mutase reaction, the initial path is generated by restrained minimization along the reaction coordinate

$$
rc = r_{\mathrm{C1-C8}} - r_{\mathrm{C3-O4}}.
$$

The resulting structures are then used to construct the 21 initial string images.

---

## 1. Generate the initial reaction path

The atoms used to define the reaction coordinate are:

```charmm
set atom1 HETA 223 C1
set atom2 HETA 223 C8
set atom3 HETA 223 C3
set atom4 HETA 223 O4
```

> Scan the reaction coordinate from −2.0 to 2.0 Å with an interval of 0.1 Å.

```charmm
set rc -2.0

label loop

resdistance reset
resdistance kval 2000.0 rval @rc -
1.0 @atom1 @atom2 -1.0 @atom3 @atom4

mini abnr nstep 2000 tolitr 2000 tolgrd 0.2 nprint 2000

trajectory write

increase rc by 0.1
if rc le 2.0 goto loop
```

The minimized structures along the scan are saved in:

```text
resd_0.dcd
```

---

## 2. Extract the initial images

The structures used as the initial string images are extracted from `resd_0.dcd`.

> Read the restrained-minimization trajectory.

```charmm
open read unform unit 1 name resd_0.dcd

trajectory query unit 1
trajectory firstu 1 nunit 1 skip 1
```

> Extract structures along the trajectory and save them as individual coordinate files.

```charmm
trajectory read

open write form unit 2 name img@{j}.crd
write coor card unit 2
close unit 2
```

This produces 21 initial structures:

```text
img1.crd
img2.crd
...
img21.crd
```

---

## 3. Calculate the CVs

For each image, calculate the C3–O4 and C1–C8 distances.

> Calculate the C3–O4 distance.

```charmm
quick HETA 223 C3 HETA 223 O4
set rc1 ?DIST
```

> Calculate the C1–C8 distance.

```charmm
quick HETA 223 C1 HETA 223 C8
set rc2 ?DIST
```

The calculated coordinates are written to:

```text
z0_all.txt
```

---

## 4. Generate `z0.txt`

The two CVs used by the string calculation are extracted from `z0_all.txt`:

```bash
awk '{print $2, $1}' z0_all.txt > z0.txt
```

The resulting `z0.txt` contains the initial C1–C8 and C3–O4 target distances for the 21 string images.

The initial setup is therefore:

```text
resd_0.dcd
     |
     v
21 initial structures
     |
     +----> img1.crd
     +----> img2.crd
     |       ...
     +----> img21.crd
     |
     v
calculate CVs
     |
     v
z0_all.txt
     |
     v
z0.txt
```

The 21 structures and their corresponding CV values in `z0.txt` are then used to start the first string iteration.

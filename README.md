# xTB/CHARMM Tutorial for Chorismate Mutase (CM)

This repository provides a complete and reproducible tutorial for running QM/MM simulations of chorismate mutase (CM) using:
*  PyCHARMM as the simulation engine
*  GFN2-xTB as the quantum mechanical method
*  CHARMM36 as the molecular mechanics force field

The tutorial is based on the workflow developed in our CM xTB/MM study, and guides users step-by-step from system preparation to free-energy analysis.

The GitHub IU Pages for this repo can be acccessed using the URL: https://pages.github.iu.edu/dl66/xtb_pycharmm/

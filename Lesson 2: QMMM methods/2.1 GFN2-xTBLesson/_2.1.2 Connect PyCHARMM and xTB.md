In the previous section, we selected chorismate as the **QM region**. 
We now connect PyCHARMM with xTB so that **GFN2-xTB** can calculate the QM energy and gradients during the QM/MM simulation.

The basic workflow is:

**PyCHARMM → coordinates and MM charges → xTB → energy and gradients → PyCHARMM**

You do not need to understand every line of the interface at this stage. The main goal is to understand how information is passed between PyCHARMM and xTB.

---

## Import the xTB Python interface

> First, import the xTB calculator and the Python packages needed for the QM/MM interface.

```python
from xtb.libxtb import VERBOSITY_MINIMAL
from xtb.interface import Calculator, Param

import numpy as np
import ctypes
```

`Calculator` is used to create the xTB calculation, while `Param.GFN2xTB` selects **GFN2-xTB** as the QM method.

---

## Define the QM atoms

> In this CM system, the chorismate substrate contains **24 atoms** and is used as the QM region.

```python
nsolu = 24

ist = 5684
ied = 5708
```

Here:

- `nsolu` is the number of atoms in the QM region.
- `ist` and `ied` identify the position of the QM atoms in the full CHARMM system.

> Next, provide the atomic numbers of the 24 QM atoms.

```python
numbers = np.array([
    6, 6, 6, 6, 8, 6, 6, 6,
    8, 8, 6, 6, 8, 6, 8, 8,
    1, 1, 1, 1, 1, 1, 1, 1
])
```

For example:

- `1` = hydrogen
- `6` = carbon
- `8` = oxygen

These atomic numbers tell xTB which elements are present in the QM region.

---

## Get the MM point charges from CHARMM

The protein, water, and ions remain in the **MM region**.

Their atomic partial charges are obtained directly from the CHARMM PSF file.

> Read the CHARMM partial charges and atomic masses.

```python
charges_sv = psf.get_charges()
charges_sv = np.array(charges_sv).flatten()

numbers_sv = psf.get_amass()
numbers_sv = np.array(numbers_sv).flatten()
```

> Convert the atomic masses into atomic numbers.

```python
for i in range(numbers_sv.size):
    numbers_sv[i] = int((numbers_sv[i] + 1.0) / 2.0)

numbers_sv = numbers_sv.astype(int)
```

> Remove the QM atoms because they will be treated directly by xTB.

```python
solu_ind = np.arange(ist, ied)

charges_sv = np.delete(charges_sv, solu_ind)
numbers_sv = np.delete(numbers_sv, solu_ind)
```

After this step:

- `numbers` describes the QM atoms.
- `numbers_sv` describes the MM atoms used as external point charges.
- `charges_sv` contains their CHARMM partial charges.

**Note:** The mass-to-atomic-number conversion used here was written for the elements present in this CM system (C, H, O, N, and S). It should not be treated as a general conversion method for arbitrary systems.

---

## Create the GFN2-xTB calculator

xTB needs an initial set of QM coordinates when the calculator is created.

> The QM coordinates are first converted from Å to Bohr because the xTB Python interface uses atomic units.

```python
positions = positions / 0.529177
```

> Create the GFN2-xTB calculator.

```python
calc = Calculator(
    Param.GFN2xTB,
    numbers,
    positions,
    charge=-2
)

calc.set_verbosity(VERBOSITY_MINIMAL)
```

For chorismate, the total QM charge is:

```text
-2
```

The calculator is created **once** outside the energy function. During the simulation, only the atomic coordinates are updated.

---

## Define the PyCHARMM–xTB energy function

The main connection between PyCHARMM and xTB is the function `e_xtb()`.

PyCHARMM provides the current atomic coordinates to this function. The function sends the QM coordinates and MM point charges to xTB, performs the xTB calculation, and returns the resulting energy and gradients to CHARMM.

> Define the energy function that will be called by PyCHARMM.

```python
def e_xtb(natoms,
          x_pos, y_pos, z_pos,
          dx, dy, dz):
```

Here:

- `natoms` is the total number of atoms in the CHARMM system.
- `x_pos`, `y_pos`, and `z_pos` contain the current atomic coordinates.
- `dx`, `dy`, and `dz` are used to return the gradients to CHARMM.

---

## Send the QM coordinates to xTB

> Extract the coordinates of the QM atoms from the complete CHARMM system.

```python
x_pos1 = x_pos[ist:ied]
y_pos1 = y_pos[ist:ied]
z_pos1 = z_pos[ist:ied]

positions = np.transpose(
    np.stack([x_pos1, y_pos1, z_pos1])
)
```

> Convert the coordinates from Å to Bohr.

```python
positions = positions / 0.529177
```

> Update the xTB calculator with the current QM coordinates.

```python
calc.update(positions)
```

This step is repeated whenever CHARMM evaluates the energy during the simulation.

---

## Send the MM environment to xTB

The QM region does not exist by itself. The surrounding protein, water, and ions influence the electronic structure of chorismate.

In this interface, these MM atoms are passed to xTB as **external point charges**.

> Extract the coordinates of all atoms outside the QM region.

```python
x_pos_sv = np.concatenate(
    (x_pos[:ist], x_pos[ied:natoms])
)

y_pos_sv = np.concatenate(
    (y_pos[:ist], y_pos[ied:natoms])
)

z_pos_sv = np.concatenate(
    (z_pos[:ist], z_pos[ied:natoms])
)

positions_sv = np.transpose(
    np.stack([x_pos_sv, y_pos_sv, z_pos_sv])
)
```

> Convert the MM coordinates from Å to Bohr.

```python
positions_sv = positions_sv / 0.529177
```

> Add the MM atoms as external point charges in the xTB calculation.

```python
calc.set_external_charges(
    numbers_sv,
    charges_sv,
    positions_sv
)
```

The GFN2-xTB calculation therefore sees the electrostatic environment surrounding the QM region.

---

## Run the xTB calculation

> Perform a GFN2-xTB single-point calculation for the current structure.

```python
res = calc.singlepoint()
```

The resulting `res` object contains the xTB energy and gradients.

---

## Get the QM energy and gradients

> Get the xTB energy.

```python
extb = res.get_energy()
```

The xTB energy is returned in Hartree.

> Get the gradients on the QM atoms.

```python
dedcc = res.get_gradient()
```

The QM gradients are returned in Hartree/Bohr.

---

## Get the gradients on the MM point charges

For QM/MM molecular dynamics, forces are also needed for the MM atoms that interact electrostatically with the QM region.

For this project, the xTB Python interface was extended with:

```python
get_pcgradient()
```

> Obtain the gradients on the external MM point charges.

```python
dedcc_mm = res.get_pcgradient(numbers_sv.size)
```

The added method in `interface.py` is:

```python
def get_pcgradient(self, npc) -> np.ndarray:

    _pcgradient = np.zeros((npc, 3))

    _lib.xtb_getPCGradient(
        self._env,
        self._res,
        _cast("double*", _pcgradient)
    )

    if self.check() != 0:
        raise XTBException(self.get_error())

    return _pcgradient
```

This method calls the xTB C-API routine `xtb_getPCGradient` and returns the gradients on the external point charges.

> **Important:** The modified `interface.py` supplied with this tutorial is required for this implementation because `e_xtb()` calls `get_pcgradient()`.

---

## Convert xTB units to CHARMM units

xTB and CHARMM use different units.

The xTB energy is converted from **Hartree to kcal/mol**, and the gradients are converted from **Hartree/Bohr to kcal/mol/Å**.

```python
extb = res.get_energy() * 627.5095

dedcc = (
    res.get_gradient()
    * 627.5095
    / 0.529177
)

dedcc_mm = (
    res.get_pcgradient(numbers_sv.size)
    * 627.5095
    / 0.529177
)
```

These conversions allow the xTB results to be used directly by CHARMM.

---

## Combine QM and MM gradients

The QM and MM gradients are returned separately by xTB.

They are combined again so that their order matches the complete CHARMM system.

```python
dedcc = np.concatenate(
    (
        dedcc_mm[:ist],
        dedcc,
        dedcc_mm[ist:natoms-nsolu]
    )
)
```

The resulting array now contains gradients for the complete QM/MM system in CHARMM atom order.

---

## Return the gradients to CHARMM

> Separate the gradients into x, y, and z components.

```python
dedcx1 = dedcc[:, 0].flatten()
dedcy1 = dedcc[:, 1].flatten()
dedcz1 = dedcc[:, 2].flatten()
```

> Convert the NumPy arrays to pointers that can be passed back to CHARMM.

```python
dedcx = dedcx1.ctypes.data_as(
    ctypes.POINTER(ctypes.c_double)
)

dedcy = dedcy1.ctypes.data_as(
    ctypes.POINTER(ctypes.c_double)
)

dedcz = dedcz1.ctypes.data_as(
    ctypes.POINTER(ctypes.c_double)
)
```

> Add the xTB gradients to the CHARMM gradient arrays.

```python
for i in range(natoms):

    dx[i] += dedcx[i]
    dy[i] += dedcy[i]
    dz[i] += dedcz[i]
```

Finally, return the GFN2-xTB energy:

```python
return extb
```

At this point, PyCHARMM has received both the **xTB energy** and the corresponding **QM/MM gradients**.

---

## Register the xTB function with PyCHARMM

The final step is very short but important.

> Register `e_xtb()` as a PyCHARMM energy function.

```python
e_func = pycharmm.EnergyFunc(e_xtb)
```

PyCHARMM can now call `e_xtb()` whenever an energy and gradient evaluation is needed.

The complete communication can be summarized as:

```
                     PyCHARMM
                        |
                        | coordinates
                        v
                    e_xtb()
                        |
             +----------+----------+
             |                     |
             v                     v
       QM coordinates       MM point charges
             |                     |
             +----------+----------+
                        |
                        v
                    GFN2-xTB
                        |
                single-point
                 calculation
                        |
             +----------+----------+
             |                     |
             v                     v
           energy              gradients
             |                     |
             +----------+----------+
                        |
                        v
                     CHARMM
```

The QM region is therefore evaluated with **GFN2-xTB**, while the surrounding protein, solvent, and ions remain part of the CHARMM MM environment.

---


In this section, we connected PyCHARMM and xTB so that:

1. PyCHARMM provides the current atomic coordinates.
2. The chorismate coordinates are sent to GFN2-xTB.
3. The surrounding MM atoms are included as external point charges.
4. xTB calculates the QM energy and gradients.
5. The QM and MM point-charge gradients are returned to CHARMM.
6. PyCHARMM can use these quantities in subsequent QM/MM calculations.

In the next section, we will use this interface to run a **single-point QM/MM energy calculation** and check that the PyCHARMM–xTB connection works correctly.

After downloading the system from CHARMM-GUI, we first run a short energy minimization to remove bad contacts and gently relax solvent before QM/MM sampling.

> First, let's Load force-field topology and parameters and read system topology (PSF) generated by CHARMM-GUI:

```
bomblev -1
stream datadir.def
stream toppar.str
open read form unit 1 name  ../../charmm-gui-3767440248/step3_pbcsetup.psf
read psf card unit 1
close unit 1
```
> Read initial coordinates (protein + ligand + solvent).
```
open read form unit 1 name  ../../charmm-gui-3767440248/step3_pbcsetup.crd
read coord card unit 1
close unit 1
```

> Define periodic boundary conditions (PBC box size, in Å). These values must match the CHARMM-GUI setup
```
set 6 83.0
set 7 83.0
set 8 83.0
```

> Define the crystal lattice (cubic box) type and geometry
```
crystal define cubi  @6 @7 @8  90.0  90.0  90.0
```

> Build the crystal along with the images within the cutoff
```
crystal build Noper 0 cutoff 20.0
```
> Protein and ligand are imaged by segment. Solvent and ions are imaged by residue
```
image byseg xcen 0.0 ycen 0.0 zcen 0.0 select segid PROA .or. segid PROB .or. segid PROC .or. segid HETA end
image byres xcen 0.0 ycen 0.0 zcen 0.0 select segid WATA .or. segid WATB .or. segid WATC .or. segid SOLV .or. segid IONS end
```
>  Nonbonded interactions and electrostatics
> Group-based cutoff
> PME for long-range electrostatics
> Parameters recommended for MNDO97/QM-MM usage
```
update -
    elec group switch cdie eps 1. -
    ewald KAPPA 0.34 spline PMEWald ORDEr 6 -
    FFTX 90 FFTY 90 FFTZ 90 -
    vdw vgroup vswitch -
    cutnb 14.0 ctofnb 13.0 ctonnb 12.0  -
    inbfrq 25 cutim 14.0 imgfrq 25 wmin 0.5
```
> Define solv and QM region (ligand segment: HETA)
```
define solv sele segid WATA .or. segid WATB .or. segid WATC .or. segid SOLV .or. segid IONS end

define qm sele segid HETA end
```
> QM/MM setup
```
mndo remo sele qm end GLNK sele none end sele none end am1 char -2 switch
```
> Constrain X–H bonds outside the QM region (SHAKE)
```
shake bonh para tol 1.0e-6 sele all end  sele  (.not. qm .and. hydrogen) end
```
> Short energy minimization (ABNR)
```
mini abnr nstep 50 tolgrd 0.2
```
> Write minimized coordinates
```
open write form unit 1 name min.pdb
write coor pdb unit 1
close unit 1

open write form unit 1 name min.crd
write coor card unit 1
close unit 1

stop
```
After energy minimization, a new coordinate file (`min.crd`) is generated.
This minimized structure will be used as the starting point to generate 21 initial coordinate files for the string-method simulations in later lessons.
